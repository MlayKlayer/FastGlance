# Security reporting

FastGlance is an early beta utility with broad local hardware access. Only the current `main` branch is maintained; there is no guaranteed security response time.

Please report vulnerabilities through [GitHub private vulnerability reporting](https://github.com/MlayKlayer/FastGlance/security/advisories/new), rather than a public issue. Include the affected commit/macOS version, steps to reproduce, impact and a minimal example. Remove credentials and personal device data.

If that reporting route is unavailable, open a public issue asking the maintainer for a private contact channel without disclosing vulnerability details.

FastGlance's microphone controls and lid-close unmount feature are convenience tools, not security or data-loss guarantees. Their current limits are described in the README.
